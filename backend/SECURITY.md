# Backend trust boundary

Owner: mainline. FastAPI implements the session/CSRF proxy described in docs/decisions/2026Q4/console_contract.md. It is localhost-only unless `PAYGUARD_DEMO_MODE=public` is set; that rules-only hosted demo binds `0.0.0.0` behind the hosting proxy, accepts only the one configured `PAYGUARD_PUBLIC_HOST`, holds no credential and answers 503 `hosted_demo_disabled` on every provider route (see SECURITY.md). Secrets are supplied only through backend environment. No browser receives credentials. Bounded sessions, rate limits and safe error responses are required before acceptance. No payment, invoice send or production deployment; Sandbox dispute evidence is sent only behind local approval, `PAYGUARD_PAYPAL_DISPUTE_SUBMIT=enabled` and `submit: true`.
