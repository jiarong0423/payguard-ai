# Backend trust boundary

Maintainer: the project author. FastAPI implements the session/CSRF proxy described in docs/decisions/2026Q4/console_contract.md. It is localhost-only unless `PAYGUARD_DEMO_MODE=public` is set; that hosted demo binds `0.0.0.0` behind the hosting proxy, accepts only the one configured `PAYGUARD_PUBLIC_HOST`, makes no PayPal calls and holds no PayPal or Google Cloud credential; only its evidence guide may call Gemini, when the operator opts in with a free-tier key held as a Render secret. Every PayPal, AI brief and AG Studio agent route answers 503 `hosted_demo_disabled` there (see SECURITY.md). Secrets are supplied only through backend environment. No browser receives credentials. Bounded sessions, rate limits and safe error responses are required before acceptance. No payment, invoice send or production deployment; Sandbox dispute evidence is sent only behind local approval, `PAYGUARD_PAYPAL_DISPUTE_SUBMIT=enabled`, `submit: true` and the server's single-use send confirmation (two Sandbox sends, 2026-11-04 and 2026-11-05).
