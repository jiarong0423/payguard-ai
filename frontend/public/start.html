Start here: judge TradeGlot in about five minutes

TradeGlot checks a sale before you ship, then helps a seller prepare dispute evidence. Rules decide, a person approves, and nothing is sent to PayPal from this page.

Open the demo and press “Try the example”

The five-minute path

  1. 1Check a sale hostedPress Try the example. A banned product to Singapore is stopped, with the rule and its official source.
  2. 2Dispute evidence hostedOpen step 03, pick a case, press Prepare evidence draft. Expect “Ready for human review” and a downloadable review ZIP. Below it, Try the send is a recorded replay: you click through the two-step send and see what the real Sandbox send recorded; nothing is sent. In the guide, what the seller sold is routed to a goods group by code (typo-tolerant fuzzy match, no model); the seller can change it, and it never decides a dispute.
  3. 3AG Studio evidence dashboard hosted recorded agent runAsk “Which reason code appears most often across the three cases?” The answer replays a real Gemini run, labelled as recorded.
  4. 4Proof and receipts recordedWhat was shown, how, when, and from which file, including the recorded real send to the PayPal Sandbox.
  5. 5Scenario work orders hostedFixed scenarios you can rerun to see the same result.

What is real, what is recorded

This hosted page’s only PayPal calls are read-only Sandbox reads (connect, list and open the author’s own Sandbox test disputes, ids masked in the list; every write is refused), and it holds no Channel3 key. Its evidence guide can call Gemini on a free-tier key under strict caps; the evidence brief and the AG Studio agents never run here. Real calls were made on the author’s local console and are shown as receipts and recordings: two PayPal Sandbox evidence sends with PayPal-Debug-Ids, one recorded AG Studio agent run, and five recorded Channel3 searches. The data is synthetic and PayPal decides every real dispute.

Prefer your own computer?

A click-through package (8 MB zip, public source plus the built console, no keys) runs the same demo locally; the send step is the same recorded replay. It needs Python 3.13 and uv; RUN_FIRST.txt inside has the one command.
