Start here: judge TradeGlot in about five minutes

TradeGlot checks a sale before you ship, then helps a seller prepare dispute evidence. Rules decide, a person approves, and nothing is sent to PayPal from this page.

Open the demo and press “Run the step 1 example”

The free server can take up to a minute to wake up on the first visit.

The five-minute path

  1. 1Check a sale hostedPress Run the step 1 example. A banned product to Singapore is stopped, with the rule and its official source.
  2. 2Dispute evidence hostedOpen step 03, pick a case, press Prepare evidence draft. Expect “Ready for human review” and a review ZIP. Below it, Try the send is a recorded replay; nothing is sent.
  3. 3AG Studio evidence dashboard hosted recorded agent runAsk “Which reason code appears most often across the three cases?” The answer replays a real Gemini run, labelled as recorded.
  4. 4Proof and receipts recordedWhat was shown, how, when, and from which file, including the recorded real send to the PayPal Sandbox.
  5. 5Scenario work orders hostedFixed scenarios you can rerun to see the same result.

What is real, what is recorded

On this page the only PayPal calls are read-only Sandbox reads of the author’s own test disputes (ids shown as masked codes); every write is refused. Five PayPal Sandbox evidence sends were made earlier on the author’s computer and are shown as receipts and notes. One AG Studio agent run and ten Channel3 searches were real too (five of the searches are replayed here). The data is synthetic and PayPal decides every real dispute.

Prefer your own computer?

A click-through package (11 MB zip, public source plus the built console, no keys) runs the same demo locally; the send step is the same recorded replay. It needs Python 3.13 and uv; RUN_FIRST.txt inside has the one command. To check our numbers yourself, run tools/verify_public_numbers.py there: it re-counts the figures on the pages (22 of 22 match).
