# Post Paypal Webhooks Verify

Source: https://jiarong0423.github.io/payguard-ai/portal/#/php/x-redirect/JTI0ZSUyRnBheXBhbCUyRnBvc3RfcGF5cGFsX3dlYmhvb2tzX3ZlcmlmeQ

Verify Webhook. Local console route POST /api/v1/paypal/webhooks/verify on synthetic data; advisory only. The hosted demo answers 503 hosted_demo_disabled here: it makes no provider calls.

```php
function postPaypalWebhooksVerify(): WebhookVerifyResponse
```


# Authentication

This endpoint requires [DemoCsrf](https://jiarong0423.github.io/payguard-ai/portal/llms-pages/php/getting-started/how-to-get-started/authorization.md) **AND** [DemoSession](https://jiarong0423.github.io/payguard-ai/portal/llms-pages/php/getting-started/how-to-get-started/authorization.md)


# Response Type

**200**: Successful Response

[`WebhookVerifyResponse`](https://jiarong0423.github.io/payguard-ai/portal/llms-pages/php/models/structures/webhook-verify-response.md)


# Example Usage

```php
$paypalController = $client->getPaypalController();

try {
    $result = $paypalController->postPaypalWebhooksVerify();
    echo 'WebhookVerifyResponse:';
    var_dump($result);
} catch (ErrorBodyException $exp) {
    echo 'Caught ErrorBodyException:', $exp;
} catch (ApiException $exp) {
    echo 'Caught:', $exp;
}
```
